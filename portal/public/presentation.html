The Enterprise Challenge

The Wild West of Agentic AI Infrastructure

Without a dedicated platform engineering control plane, AI development teams face systemic operational and security friction:

❌ Ungoverned Ad-Hoc AI Stacks

  • Static GCP service account JSON keys committed to git repositories.
  • Direct data plane exposure with unmanaged public ingress.
  • Runaway cloud costs with no TTL expiration or orphan resource tracking.
  • Prompt injection, jailbreak vulnerabilities, and unredacted PII leakage.

✅ The Governed IDP Solution

  • Self-service catalog with version-pinned, immutable AI templates.
  • Asynchronous control plane with atomic concurrency locking.
  • Pre-activation readiness smoke tests verifying AI response fidelity.
  • Integrated Model Armor guardrails and automated TTL lifecycle cleanup.

Control Plane

Enterprise Authentication & Sessions

Robust, standards-compliant identity management built for developer velocity and operational security.

Argon2id Cryptographic Hashes

Enforces OWASP recommended memory-hard password verification to prevent offline dictionary and GPU brute-force attacks:

• Memory Cost: 65,536 KiB (64 MiB)
• Time Cost: 3 iterations
• Parallelism: 4 concurrent threads

60-Minute JWT Bearer Tokens

Stateless authentication with immediate revocation capabilities for incident response:

• Lifetime: Strict 3600 seconds (1 hour)
• Secret Key: Google Secret Manager
• Instant Revocation: User token_version increment
Reliability Engine

Concurrency Locking & 24h Idempotency

Eliminating race conditions, duplicate infrastructure orders, and out-of-order execution states.

24h TTL SHA-256 Idempotency

Every mutation endpoint requires an Idempotency-Key header.

  • Exact payload replayed within 24 hours returns cached HTTP 202 response.
  • Modified payload with identical key returns HTTP 409 Conflict.
  • Prevents duplicate billing and multiple VM/model instances.

Atomic Deployment Locking

Active requests hold exclusive locks in Firestore:

  • Deployments in PENDING or PROVISIONING reject concurrent updates.
  • Teardowns blocked until provisioning pipeline completes or fails.
  • Locks automatically released upon terminal callback receipt.
Template Portfolio

T1 — Vertex AI Agent Engine

Governed ADK-based autonomous agent instances running on Vertex AI reasoning engine infrastructure.

Architecture & Constraints

  • Framework: Agent Development Kit (ADK) GovernedAgent runtime.
  • Models: Strict whitelist: gemini-2.5-flash, gemini-2.5-pro.
  • Regions: Pinned to approved regions: us-central1.
  • Packaging: Version-pinned wheel artifacts uploaded to GCS.

Pre-Activation Smoke Test

A deployment is never marked ACTIVE based on Terraform exit codes alone. The pipeline executes smoke_test.py:

1. Query agent with ping stimulus
2. Verify JSON reasoning response
3. Validate latency < 5000ms
4. Post SUCCEEDED callback only on pass

Governance & Guardrails

T4 — Model Armor & Operational Controls

Multi-layered prompt security, PII sanitization, metric alerting, and automated TTL cleanup.

Model Armor Guardrails

Screens prompts, tool inputs, retrieved content, and model outputs:

• BLOCK: Strict rejection of prompt injections & jailbreaks.
• REDACT: Automatic masking of SSNs, credit cards, and emails.
• ALLOW_WITH_AUDIT: Permitted execution with security ledger logging.

TTL & Monitoring Controls

Active cost control and observability:

• Default 7-Day TTL: Development workloads expire automatically.
• Admin Override: Auditable TTL extensions with reason tracking.
• Automated Cleanup: Scheduled workflow destroys expired workloads.
• Cloud Monitoring: Alert policies for error spikes and budget warnings.
Deployment Gating

Production Gate & Notification Boundary

Enterprise change control: Dual-stage workflows with mandatory reviewer approval and event notifications.

GitHub Environment Approval Gate

Workflows split into plan and apply stages:

  • API validates role: Only platform_admin can target prod environment.
  • Job plan runs and saves plan summary.
  • Job apply holds execution until designated reviewers approve.
  • Prevents accidental or unauthorized changes to production infrastructure.

Pub/Sub Event Notification Boundary

Decoupled event boundary for enterprise communications:

  • Control Plane emits normalized lifecycle events across Pub/Sub boundary.
  • Notification service formats rich Slack BlockKit webhook cards.
  • Strict data scrubbing: Secrets, keys, and state files strictly excluded.
  • Instant alerting on provisioning successes, failures, and TTL teardowns.
